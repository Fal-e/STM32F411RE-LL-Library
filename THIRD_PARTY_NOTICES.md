# Third-Party Notices

This repository includes project-authored code and bundled third-party/vendor files. The root [LICENSE](LICENSE) applies to the project-authored code unless a file or directory carries its own license notice.

This document records the third-party files identified during the public-maintenance revival. It is based on license headers, bundled license PDFs, and readme files currently present in the repository.

## ARM CMSIS Files

Bundled CMSIS headers are present in these directories:

- `GPIO_Driver/Drivers/CMSIS/`
- `Timers/Drivers/CMSIS/`
- `Tutorial1/Drivers/CMSIS/`
- `stm32_ssbp/Libraries/CMSIS/`

Representative files include ARM copyright and permissive redistribution terms:

- `*/Drivers/CMSIS/Include/core_cm*.h`
- `*/Drivers/CMSIS/Include/arm_math.h`
- `*/Drivers/CMSIS/Include/arm_common_tables.h`
- `*/Drivers/CMSIS/Include/arm_const_structs.h`

Bundled CMSIS license documents are also present:

- `GPIO_Driver/Drivers/CMSIS/CMSIS_END_USER_LICENCE_AGREEMENT.pdf`
- `Timers/Drivers/CMSIS/CMSIS_END_USER_LICENCE_AGREEMENT.pdf`

Representative paths include:

The role of `stm32_ssbp/` in this STM32F411RE repository still needs scope review.

## Notes for Maintainers

- Do not assume the root MIT license replaces notices embedded in bundled third-party/vendor files.
- Do not remove bundled license files unless the corresponding vendor files are also removed or replaced in a later, verified cleanup.
- Vendor de-duplication is intentionally deferred until build/import behavior is verified.
